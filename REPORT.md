# Звіт до лабораторної роботи №1

## 1. Тема, номер і варіант

**Лабораторна робота №1:** «Розгортання Java-проєкту та базова обробка даних».

**Варіант:** 8 — Каталог фільмів (Movie Catalog).

**Операційна система:** Windows.

## 2. Мета роботи

Метою лабораторної роботи є створення консольного Java-проєкту з використанням Maven, реалізація базової обробки даних із CSV-файлу, перевірка коректності вхідних даних, написання модульних тестів, виконання статичного аналізу та налаштування автоматичної перевірки проєкту за допомогою GitHub Actions.

## 3. Постановка задачі

Необхідно реалізувати консольну програму для обробки каталогу фільмів.

Для кожного фільму використовуються такі поля:

* `title` — назва фільму (`String`);
* `director` — режисер (`String`);
* `year` — рік випуску (`int`);
* `minutes` — тривалість у хвилинах (`int`);
* `rating` — рейтинг (`double`).

Програма повинна:

1. прочитати дані з CSV-файлу;
2. перевірити коректність кожного запису;
3. не завершувати роботу через некоректний рядок;
4. визначити кількість коректних записів;
5. обчислити середній рейтинг;
6. визначити найдовший фільм;
7. визначити найстаріший рік;
8. сформувати звіт у текстовому файлі;
9. підтримувати параметри командного рядка `--help`, `--version`, `--input` та `--output`.

У тестових даних використано як коректні, так і некоректні записи, а також українські символи.

## 4. Структура програми

Проєкт має Maven-структуру:

```text
kzp-lab1-herei/
├── .github/
│   └── workflows/
│       └── ci.yml
├── data/
│   └── input.csv
├── out/
├── src/
│   ├── main/
│   │   └── java/
│   │       └── ua/
│   │           └── lpnu/
│   │               └── kzp/
│   │                   └── Main.java
│   └── test/
│       └── java/
│           └── ua/
│               └── lpnu/
│                   └── kzp/
│                       └── MainTest.java
├── .editorconfig
├── .gitattributes
├── .gitignore
├── pom.xml
├── mvnw
├── mvnw.cmd
├── README.md
└── REPORT.md
```

Основна логіка програми знаходиться у файлі `Main.java`.

У програмі реалізовано:

* читання файлу через `Path`;
* використання UTF-8;
* розділення CSV-рядка за допомогою `split(";", -1)`;
* перевірку кількості полів;
* перевірку числових значень;
* обробку `NumberFormatException`;
* пропуск некоректних записів без завершення програми;
* обчислення статистичних показників;
* формування текстового звіту;
* створення директорії для вихідного файлу за потреби.

## 5. Інфраструктура проєкту

Для складання проєкту використовується **Maven**.

У `pom.xml` налаштовано:

* Java 21;
* UTF-8;
* JUnit 5;
* Maven Wrapper;
* SpotBugs для статичного аналізу;
* Maven Shade Plugin для створення виконуваного JAR-файлу.

Для запуску Maven у Windows використовується Maven Wrapper:

```powershell
.\mvnw.cmd test
```

Перевірка всього проєкту:

```powershell
.\mvnw.cmd verify
```

Створення JAR:

```powershell
.\mvnw.cmd package
```

Після виконання `package` створюється виконуваний файл:

```text
target/kzp-lab1-herei-1.0.0-shaded.jar
```

Також налаштовано GitHub Actions. CI виконує перевірку проєкту на:

* Ubuntu;
* Windows;
* macOS.

Для всіх операційних систем використовується Java 21 та команда `verify`. Після успішної перевірки JAR-файли зберігаються як CI artifacts.

## 8. Тестування

Для модульного тестування використано **JUnit 5**.

У класі `MainTest` перевіряється:

1. наявність коректних записів та українських символів у вхідному файлі;
2. створення вихідного файлу `out/report.txt`;
3. правильна обробка параметра `--version`.

Тести запускаються командою:

```powershell
.\mvnw.cmd test
```

Результат виконання тестів — успішний.

Також було виконано повну перевірку Maven:

```powershell
.\mvnw.cmd verify
```

Команда завершилася успішно.

Для статичного аналізу використовується SpotBugs. Попередження, яке виникало під час розробки, було виправлено.
