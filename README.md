# Лабораторна робота №1

## Розгортання Java-проєкту та базова обробка даних

**Дисципліна:** Кросплатформне програмування
**Варіант:** 8
**Тема варіанта:** Каталог фільмів (Movie Catalog)

## 1. Опис завдання

Програма призначена для обробки каталогу фільмів із CSV-файлу.

Для кожного фільму використовуються такі поля:

1. `title` — назва фільму (`String`);
2. `director` — режисер (`String`);
3. `year` — рік випуску (`int`);
4. `minutes` — тривалість у хвилинах (`int`);
5. `rating` — рейтинг (`double`).

Програма обробляє коректні записи та пропускає некоректні записи, формуючи список помилок.

## 2. Розраховувані показники

Для коректних записів програма визначає:

* кількість коректних записів;
* середній рейтинг;
* найдовший фільм;
* найстаріший рік.

Середній рейтинг виводиться з точністю до двох знаків після десяткової крапки.

## 4. Вимоги

Для запуску проєкту необхідно мати:

* JDK 21 або сумісну версію Java;
* Maven Wrapper, який використовується для збірки та тестування.

Проєкт використовує Maven для керування залежностями, тестування та збирання JAR-файлу.

## 5. Запуск тестів

Для запуску JUnit-тестів у Windows:

```powershell
.\mvnw.cmd test
```

Для повної перевірки проєкту:

```powershell
.\mvnw.cmd verify
```

## 6. Збірка проєкту

Для створення JAR-файлу:

```powershell
.\mvnw.cmd package
```

Після успішної збірки JAR-файл знаходиться у каталозі `target`.

Поточна назва executable JAR:

```text
target/kzp-lab1-herei-1.0.0.jar
```

## 7. Запуск програми

Стандартний запуск:

```powershell
java -jar target\kzp-lab1-herei-1.0.0.jar
```

За замовчуванням програма використовує:

```text
data/input.csv
```

та записує звіт у:

```text
out/report.txt
```

## 8. Параметри командного рядка

### Довідка

```powershell
java -jar target\kzp-lab1-herei-1.0.0.jar --help
```

Показує доступні параметри та приклади використання програми.

### Версія

```powershell
java -jar target\kzp-lab1-herei-1.0.0.jar --version
```

Результат:

```text
kzp-lab1-herei version 1.0.0
```

### Власний вхідний файл

```powershell
java -jar target\kzp-lab1-herei-1.0.0.jar --input data\input.csv
```

### Власний файл звіту

```powershell
java -jar target\kzp-lab1-herei-1.0.0.jar --output out\custom-report.txt
```

### Власний вхідний та вихідний файли

```powershell
java -jar target\kzp-lab1-herei-1.0.0.jar --input data\input.csv --output out\custom-report.txt
```

## 9. Формат вхідних даних

Файл `data/input.csv` містить записи у форматі:

```text
title;director;year;minutes;rating
```

Наприклад:

```text
Зелена миля;Френк Дарабонт;1999;189;9.0
```

У тестових даних присутні як коректні, так і некоректні записи.

Програма обробляє некоректні рядки без аварійного завершення роботи та додає інформацію про помилку до звіту.

## 10. Валідація даних

Під час обробки перевіряються:

* кількість полів;
* непорожня назва фільму;
* непорожній режисер;
* коректність числових значень;
* додатність року;
* додатність тривалості;
* невід'ємність рейтингу.

Для розділення CSV-полів використовується:

```java
split(";", -1)
```

що дозволяє коректно виявляти порожні поля.

## 11. Формування звіту

Приклад результату:

```text
КАТАЛОГ ФІЛЬМІВ

Кількість коректних записів: 5
Середній рейтинг: 8.08
Найдовший фільм: 194 хв
Найстаріший рік: 1997

Помилки:
Рядок 6: неправильне числове значення
Рядок 7: порожній режисер
```

Звіт записується у файл UTF-8.

## 12. Кодування

Для роботи з текстовими файлами явно використовується UTF-8:

```java
StandardCharsets.UTF_8
```

Це забезпечує коректну роботу з українськими символами у вхідному файлі та звіті.

## 13. Тестування

Для тестування використовується JUnit 5.

Тести перевіряють:

* наявність вхідного файлу;
* наявність українських символів у тестових даних;
* створення файлу звіту;
* роботу параметра `--version`.

Запуск:

```powershell
.\mvnw.cmd test
```

## 14. Статичний аналіз

Для статичного аналізу коду використовується SpotBugs.

Повна перевірка:

```powershell
.\mvnw.cmd verify
```

## 15. GitHub Actions

Проєкт містить GitHub Actions для автоматизованої перевірки проєкту.

CI використовується для автоматичного запуску перевірок під час роботи з репозиторієм.

## 16. Результат

У результаті виконання лабораторної роботи створено Java-проєкт для обробки каталогу фільмів, реалізовано перевірку вхідних даних, обчислення необхідних показників, формування звіту, JUnit-тести, статичний аналіз та запуск програми через executable JAR.

Проєкт підтримує параметри:

```text
--help
--version
--input
--output
```
