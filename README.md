## Клас-сутність і валідація (лабораторна № 2)
`Movie` — незмінний клас (`private final` поля, лише геттери). Конструктор перевіряє:
- назва і режисер: не `null`, не порожні;
- рік > 0, тривалість > 0;
- рейтинг скінченний, у діапазоні [0; 10] (верхня межа додана в ЛР № 2).

`Movie.fromCsv` розбирає структуру рядка (5 полів, числа), конструктор — інваріанти.
`YearRating` — `record` з підсумковими показниками. `CatalogService` — розбір, підсумок,
текст звіту.

## Відмінності від лабораторної № 1
| Було | Стало |
|---|---|
| рядок, `split` і індекси в циклі | об'єкт `Movie` + `Movie.fromCsv` |
| паралельні змінні лічильників | `List<Movie>` |
| окремі змінні підсумку | `record YearRating` |
| перевірки в циклі | перевірки в конструкторі |

Формат CSV, показники та формат звіту не змінено.
